# Roadmap

## Planned Enhancements

- DMA support for I2C and SPI transfers
- Interrupt-based UART receive and transmit handling
- RTC timestamping for log entries and display
- UART command interface for configuration and diagnostics
- Firmware update support using a bootloader

## Future Extensions

- Cloud gateway support for MQTT upload
- Battery and power monitoring
- Secure OTA updates for embedded firmware
- Adaptive logging frequency based on sensor thresholds
