# BME280 Driver

This directory contains the sensor driver and implementation details for the Bosch BME280 environmental sensor.

Expected items:

- `bme280.c` / `bme280.h`
- sensor initialization and configuration
- I2C read/write wrappers
- temperature/humidity/pressure compensation logic

> The original BME280 example is available in `BME280/I2C/` in this repository.
